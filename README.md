# enhance-x

Xの不要なおすすめ欄を非表示にするChrome拡張（Manifest V3）。ビルド不要です。

## 非表示にするもの

- サイドバーの「『いま』をみつけよう」「いまどうしてる？」などのトレンド欄
- 「おすすめユーザー」（サイドバーとタイムライン内）
- サイドバーの「本日のニュース」
- ホームの「おすすめ」タブ（選択中の場合は「フォロー中」に切り替え）
- 左メニューの「話題を検索」「Grok」「プレミアム」「クリエイタースタジオ」
- サイドバーの「プレミアムにサブスクライブ」（「プレミアム」設定と連動）

日本語・英語の見出しに対応しています。検索欄や通常の投稿は残します。

## インストール

1. このリポジトリをダウンロードまたはcloneする。
2. Chromeで `chrome://extensions` を開く。
3. 右上の「デベロッパーモード」を有効にする。
4. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダーを選ぶ。
5. 開いているXのタブを再読み込みする。

更新後は拡張機能の「更新」ボタンを押してからXを再読み込みしてください。

## 設定

Chromeの拡張機能一覧からEnhance Xのアイコンをクリックすると、8項目の非表示を個別に切り替えられます。
チェックありで非表示、チェックなしで表示です。初期状態ではすべて非表示です。
設定はこのブラウザー内に自動保存され、開いているXにも再読み込みなしで反映されます。
「おすすめ」タブを表示に戻しても、選択中のタイムラインはそのままです。

## 動作確認

- ホームで「おすすめ」が消え、「フォロー中」の投稿が表示される。
- サイドバーの対象欄が消え、検索欄が残る。
- 左メニューの対象4項目が余白ごと消え、ホーム・通知などは残る。
- スクロールやプロフィールからの画面内遷移後も対象欄が消える。
- おすすめ欄と同じ文言を含む通常の投稿は表示される。

XのDOM構造や見出しが変わった場合、セレクターの調整が必要になることがあります。
ログイン済みのX実画面での確認は別途必要です。

## 構成

- `manifest.json`: 対象サイトとcontent scriptの指定
- `content.css`: 既知の欄と検出済み要素の非表示
- `content.js`: 見出し検出・ホームタブ切り替え・動的更新への追従

外部通信は行いません。設定のみをChromeのローカルストレージに保存します。
ページの変更はXと旧Twitterのページ上でのみ動作します。
content scriptの構成は[Chrome公式ドキュメント](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)を参照。
